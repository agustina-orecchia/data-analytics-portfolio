# Data Analytics Portfolio

Tina Orecchia · Data & Business Analyst · Brisbane, Australia

Analysis projects built on public Australian data, with a focus on health and care services. Each project starts from a real business question, documents how the data was validated, and states its limitations.

**Tools:** SQL · Python · Databricks · Power BI · Excel

## Projects

| Project | Question | Methods |
|---|---|---|
| [Queensland flu season forecast](qld-flu-season-forecast/) | When will Queensland's 2027 flu season peak, and what does that mean for vaccination timing in aged care? | Time-series shape analysis, backtesting, ensemble forecast, bootstrap intervals |

## Approach

- **Start with the decision.** Every project names who would use the result and what they would do differently.
- **Validate before analysing.** Totals are reconciled against published figures, and exclusions are stated.
- **Be honest about uncertainty.** Forecasts come with intervals and backtests, and limitations are written down.
